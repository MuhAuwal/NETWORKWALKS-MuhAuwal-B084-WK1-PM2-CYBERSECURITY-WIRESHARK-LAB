# Week 1 – Wireshark SOC Analyst Practical Labs

## Project Overview

This repository documents my completion of the **Week 1 Wireshark Project Module (Extra)** as part of the Networkwalks Cybersecurity Internship.

The project involved working through six practical Wireshark browser-based labs designed to develop hands-on skills in network traffic analysis and Security Operations Centre (SOC) investigations.

## Objectives

- Analyse network traffic using Wireshark.
- Identify suspicious and potentially malicious IP addresses.
- Inspect TCP streams and reconstruct network communications.
- Identify credentials transmitted in plain-text HTTP traffic.
- Investigate brute-force attack patterns.
- Analyse VoIP traffic and identify suspicious call activity.

## Labs Completed

The following six practical labs were covered:

| No. | Lab | Focus |
|---|---|---|
| 1 | Identify the Attacker's IP | Identifying suspicious IP addresses |
| 2 | Follow TCP Stream 1 | Inspecting TCP communication |
| 3 | Follow TCP Stream, Part 2 | Reconstructing network conversations |
| 4 | HTTP Plain Text Credentials | Identifying exposed credentials |
| 5 | Catch the Brute Force Attacker | Investigating brute-force activity |
| 6 | Catch the Call Scammer | Analysing VoIP traffic |
